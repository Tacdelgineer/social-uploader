Short-form publishing workflow

Upload once. Publish to your own connected accounts.

Social Uploader lets an authorized user prepare one short-form video, choose destinations, set the caption and supported publishing options, and schedule delivery to accounts that user has explicitly connected.

01

Connect

The user authorizes each social account through the provider's official OAuth flow. Provider credentials remain server-side.

02

Choose

The user selects each destination and reviews its available settings. TikTok posting requires an explicit selection and consent before any transfer begins.

03

Deliver

The application uses official provider APIs, shows per-platform status, and does not automatically repost a successful delivery.

TikTok integration

Login Kit connects the user's own TikTok account. Before Direct Post, Social Uploader requests the latest creator information, displays the privacy and interaction settings TikTok makes available, checks video duration, and requires explicit consent. Videos are transferred with FILE_UPLOAD and posting status is tracked in the dashboard.

Public TikTok posting requires TikTok production approval. Until approval, TikTok applies its unaudited-client restrictions.
